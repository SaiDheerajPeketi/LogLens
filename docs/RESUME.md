# Resume Description

Built LogLens, a React/TypeScript and FastAPI incident-analysis app that combines XGBoost anomaly evaluation on 575,061 LogHub HDFS traces with a calibrated synthetic-family root-cause classifier and citation-validated redacted evidence. Packaged the system as a 178 MB Docker service with SQLite queueing, measuring 0.9994 PR-AUC, 0.9956 anomaly F1, 1.0000 synthetic RCA macro-F1, and 100% citation validity across six runtime cases.
