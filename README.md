# LogLens

Evidence-first log anomaly detection and root-cause analysis.

LogLens is under active development. The first release will include a reproducible ML pipeline, FastAPI service, React flight-recorder console, local Docker deployment, honest evaluation results, and a 60-second walkthrough.

## Current status

The product contract and decision journal are complete. The service and interface are being implemented in small, tested commits.
